# 🏛️ The Grand Portfolio Villa

An immersive, interactive portfolio experience that transports visitors through a luxurious villa with stunning visual effects and engaging interactions.

## ✨ Experience Overview

### 🚪 The Entrance
- Arrive at a grand villa under a starlit night sky
- Approach an ornate wooden door with iron fixtures
- Tap the door to enter - watch it swing open with dramatic lighting

### 🏛️ The Grand Gallery
- Enter a magnificent hall illuminated by a golden chandelier
- Explore 5 unique rooms, each revealing different aspects of the portfolio
- Hover over doors to preview what awaits inside

### 🚪 The Rooms

| Room | Description | Content |
|------|-------------|---------|
| 🏆 **Trophy Hall** | Awards & Honors | Professional awards, academic honors |
| ⭐ **Star Chamber** | Achievements | Career milestones, technical achievements |
| 📜 **Chronicle Room** | Experience | Professional timeline, skills, education |
| 🏗️ **The Workshop** | Projects | Featured projects, open source work |
| 🖼️ **Art Gallery** | Visuals | UI designs, 3D art, photography |

## 🎨 Visual Features

- **Night Sky** with twinkling stars and crescent moon
- **Torch-lit** villa entrance with animated flames
- **Wooden Door** with realistic grain texture and iron hardware
- **Chandelier** with flickering candle effects
- **Dust Particles** floating in gallery atmosphere
- **Smooth Transitions** between scenes
- **Hover Effects** on interactive elements

## 🛠️ Technologies

- **HTML5** - Semantic structure
- **CSS3** - Advanced animations and gradients
- **JavaScript** - Interactive scene management
- **Google Fonts** - Cinzel & Cormorant Garamond

## 🚀 Getting Started

Simply open `index.html` in a modern web browser to experience the portfolio.

```bash
# If you have a local server
npx serve .

# Or using Python
python -m http.server 8000
```

## 📱 Responsive Design

The portfolio is fully responsive and works beautifully on:
- 📱 Mobile devices
- 📱 Tablets
- 💻 Laptops
- 🖥️ Desktops

## 🎭 Interactions

1. **Knock on the door** - Click/tap the entrance door
2. **Watch the door open** - Dramatic reveal with light effects
3. **Explore the gallery** - Hover over room doors to preview
4. **Enter a room** - Click any room to view its contents
5. **Navigate back** - Use the back button to return to gallery

## 📝 Customization

Edit the content in `script.js` to personalize:
- Awards and honors
- Achievement milestones
- Work experience timeline
- Project showcases
- Gallery items
